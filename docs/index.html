CATHACTION Participant Repository

Université de Rennes · MICCAI 2026 challenge participant workspace

This repository contains our working code, experiments, Docker packaging, figures, and final method report for CATHACTION: Endovascular Intervention Tool Segmentation and Collision Detection.

Read the workflow guide

The 2026-04-22 challenge PDF is the current source of truth for this repo. The public website is useful background but currently contains older dataset counts.

Working Facts

  • 650 fluoroscopy videos/cases.
  • Domains: silicon phantom, preclinical animal X-ray, real human X-ray.
  • About 40,000 segmentation frames and about 600,000 collision-label frames.
  • 70/15/15 split at procedure/case level.
  • Docker container plus result file and method description expected for submission.

Workflow

Non-trivial work starts with a saved plan in quality_reports/plans/. After approval, implementation proceeds autonomously and ends with verification: tests, metric checks, Docker smoke tests, renders, or a documented blocker.

Non-Negotiables

  • No case-level leakage.
  • No private/proprietary clinical data.
  • No hidden-test hand tuning.
  • Every reported result must trace to code, config, split, checkpoint, command, and output.
  • Figures must be publication-ready and explicit about metric, domain, and sample.
