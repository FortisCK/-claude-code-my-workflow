CATHACTION Workflow Guide

Université de Rennes · participant repo for MICCAI 2026 CATHACTION

Purpose

This repository is the working participant repository for CATHACTION, a MICCAI 2026 challenge on endovascular intervention tool segmentation and collision detection. It is expected to contain the full submission lifecycle: code, experiments, Docker packaging, metrics, publication-ready figures, and the final method description or paper.

Source Of Truth

Use the 2026-04-22 CATHACTION challenge PDF as the current source of truth. The public website is useful background, but at the time of configuration it still showed older counts. Record any later source-of-truth change in quality_reports/decisions/.

Challenge Facts

ItemWorking Fact
Task 1Catheter and guidewire segmentation in X-ray fluoroscopy; DSC primary.
Task 2Collision detection in endovascular intervention; mAP primary.
DomainsSilicon phantom, preclinical animal X-ray, real human X-ray.
Cases650 videos/procedures.
Annotated framesAbout 40k segmentation frames and about 600k collision-label frames.
Split70/15/15 at procedure/case level.
SubmissionDocker container, result file, short method description/report.

Collaboration Protocol

  1. Save a plan under quality_reports/plans/.
  2. Ask for approval.
  3. Execute autonomously after approval.
  4. Verify with tests, metric checks, Docker smoke tests, manuscript renders, or documented blockers.
  5. Update session logs and memory when decisions or corrections occur.

Non-Negotiables

  • Split by case/procedure, never by random frame.
  • Treat DSC as the primary Task 1 ranking metric.
  • Treat mAP as the primary Task 2 ranking metric.
  • Use only public external data and pretrained models allowed by challenge policy.
  • Keep hidden-test inference automated and free of manual curation.
  • Trace every reported number to code, config, split, checkpoint, command, and output.
  • Make figures paper-ready and explicit about metric, domain, and sample.
