## Intent

Pretrain the Stage-1 KL-VAE on ImageCAS clean cardiac CT volumes. The VAE is the
**frozen encoder** consumed by Stage-2 conditional latent diffusion: it must
produce latents at `(B, 4, 24, 24, 24)` (8× spatial compression of 192³) whose
decoded reconstructions retain enough cardiac structure for downstream coronary-
lumen evaluation to be meaningful.

**Falsifiable expectation:** validation PSNR ≥ 30 dB and SSIM ≥ 0.90 by epoch 100
on the 5% holdout. If PSNR < 25 dB or SSIM < 0.85 → reconstruction quality is
not sufficient to support Stage-2; iterate with perceptual loss (LPIPS) and/or
adversarial loss in v2 (we deliberately omitted both in v1 to debug recon + KL
+ SSIM first; see plan `quality_reports/plans/atomic-munching-naur.md` Step 3).

If KL term collapses (latent variance → 0) or explodes (latent variance → ∞)
before epoch 30 → free-bits or β-warmup is needed; abort and iterate.

## Hyperparameters (delta from previous best)

First training run on this branch — no previous best. Baseline configuration
chosen from MONAI 3D AutoencoderKL tutorial defaults, adapted for cardiac CT:

- Architecture: channels (32, 64, 128, 128); num_res_blocks (2, 2, 2, 2);
  attention only at deepest level; latent_channels=4; norm_num_groups=32
- Loss: `L = L1(x, x̂) + 1e-6 · KL + 0.1 · (1 − SSIM)` (no perceptual, no adversarial in v1)
- Optimizer: Adam(lr=1e-4, β=(0.9, 0.999), wd=0)
- Batch size 2 (tight at 192³ × FP16); AMP via `torch.autocast(fp16)`
- 100 epochs, val every 5 epochs, ckpt every 10 epochs
- Data augmentation: random flip (p=0.5 per axis), rotate ±5°, shift ±2 voxels,
  intensity shift ±0.05

Notable v1 simplifications (documented for v2 follow-up if needed):
- No perceptual / adversarial loss (defer to v2 if recon insufficient)
- `use_checkpoint=False` (revisit if OOM at full batch)
- `cudnn.benchmark=True` (training-speed default, not numerical-replication)

### What happened

The v1 recipe was useful for debugging the data path and confirming the memory
budget, but it did not reach the reconstruction quality needed for the latent
diffusion stage. Whole-volume 192^3 training forced batch size 1, and the loss
recipe omitted perceptual and adversarial terms.

### Decision

Do not use v1 for Stage-2. It was superseded by the MAISI-style v2 recipe and
then by the 128^3 v2 finetune recorded in
`experiments/runs/2026-05-14_0411_vae-v2-128-finetune.md`.
