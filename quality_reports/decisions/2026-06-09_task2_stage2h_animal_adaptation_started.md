# Task 2 Stage2H Animal Adaptation Diagnostic Started

## Purpose

Previous Task 2 detectors were trained on `train_clean`, which contains phantom samples only. They performed poorly on animal collision cases, especially class 1. Stage2H tests whether adding a small amount of labeled animal collision data improves held-out animal detection when the split is still video/procedure-level.

This is a diagnostic experiment, not a clean leaderboard-equivalent validation result. Metrics from this run should not be mixed with the original no-leakage `valid_animal` report because one animal video is moved into training.
